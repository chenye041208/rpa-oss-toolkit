# 版本发布说明

> **项目名称**：阿里云 OSS 库（aliyunoss_rpa）
> **开发语言**：Python 3
> **业务场景**：为 RPA 流程提供阿里云 OSS 文件操作能力

---

## v1.0.0（2026-04-25）

### 新增

- 基于会话机制的阿里云 OSS 操作库，先创建会话验证连接，后续操作通过会话执行
- 完整 CRUD：上传、下载、删除、列举、复制、文件存在判断、签名 URL 生成
- 大文件自动分片上传/下载（>5MB 自动切换分片模式），支持多线程并发传输
- 分片传输失败自动重试（指数退避），最大重试 3 次
- 操作日志自动写入 OSS 远程存储，无需本地磁盘
- 日志缓冲区设计（50 条阈值），攒满自动刷新，减少网络 IO
- 多会话日志防冲突机制（基于 lock 文件）
- 会话上下文管理器支持（`with` 语句），自动关闭释放资源
- Session 对象可直接传递给 RPA 平台组件使用
- 文件元数据读写（Content-Type、Content-Length、Last-Modified、ETag）
- 会话有效期管理，过期自动失效
- 自定义异常体系（OSSError 基类 + 10 个子类），精确捕获各类错误
- OSS 键名合法性校验，支持控制字符检测与路径规范化
- 配置集中管理（日志路径、缓冲区大小、分片阈值、重试策略等均可调）
